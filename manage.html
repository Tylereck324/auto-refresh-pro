Auto-Start URLs on Browser Open
URL Rules (auto-start on matching pages)
When a tab finishes loading a URL matching a pattern, refresh starts automatically. Patterns use Chrome match syntax, e.g. *://*.example.com/* or https://news.site/*.
Domain Denylist
Auto refresh will never start on these sites (banking, webmail, etc.). Patterns: an exact host (mail.google.com), a leading wildcard (*.bank.com = the domain and any subdomain), or * (everything).
